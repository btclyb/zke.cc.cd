# 交易复盘模板

这是一篇**示例笔记**，用来演示格式。你可以直接改写，或者把 `index.json` 里的这一条删掉。

## 为什么要复盘

事前写下逻辑，事后才能知道自己是判断对了，还是只是运气好。

> 结果好不代表决策好，结果差也不代表决策差。

## 每笔交易记录这几项

1. **标的与方向**：做多还是做空
2. **入场理由**：用一两句话写清楚
3. **风险**：最多愿意亏多少，在哪里认错
4. **离场条件**：逻辑失效，或者达到目标

## 事后复盘问题

- 当时的逻辑成立吗？
- 我有没有按计划执行？
- 如果重来一次，我会改什么？

| 标的 | 例：BTC |
| 方向 | 例：多 |
| 结论 | 例：逻辑成立，执行到位 |
